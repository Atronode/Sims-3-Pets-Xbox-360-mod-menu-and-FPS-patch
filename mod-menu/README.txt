THE SIMS 3 PETS - MOD MENU

HOW TO START THE GAME WITH THE MENU
1. Close Xenia if it is open.
2. Double-click "Play Sims 3 Pets (Mod Menu).bat" in this folder.
3. The game opens along with a small black window. Leave that window open while you play.
   It closes by itself when you close the game.
4. Load your save as normal. Karma powers unlock by themselves each time a game loads.

Always start the game with this file. If you open the game from Xenia directly, there is no menu.
Going back to the main menu and loading another game is fine: the menu comes back by itself.
Keep this folder next to your xenia folder and your game's .iso file. The file's name must include Sims, 3 and Pets.

HOW TO OPEN THE MENU
Hold LT, then press A while pointing at a Sim, a pet, the ground or an object.
Press B to go back or close it. If there are too many options, push the stick up or down to scroll.

If several things are close together, the menu opens on the first one, which is usually the Sim.

RELATIONSHIPS
On a Sim, Relationships holds every relationship type: friendship, rivalry, romance and family. Pick one, tick
as many Sims as you like in the list, then press X: each of them gets that relationship with the Sim you clicked.
The game's own romance rules still apply: no children, teens only with teens, and no relatives.

EMPTY HOUSES
Point at an empty house (a furnished home nobody lives in), or at its yard, to move randomly made Sims in:
one Sim, a married couple, or a family. Fill Every Empty House puts one Sim in every empty house in town.
Each new household starts with 20,000 Simoleons.

FRAME RATE (60 FPS PATCH)
The game normally runs at up to 30 frames per second.
1. Close Xenia.
2. Double-click "Sims 3 Pets FPS Patch.bat" in this folder.
3. Press 1 for 60 FPS (recommended), 2 for unlocked, or 3 to go back to 30.
4. Press 4 to turn Smart screen copies on (recommended), then 7 to close.
Xenia's title bar shows [Patches Applied] when it is working. The game's clock still runs at normal speed.
The patch also stops the game dropping straight from 60 to 30 FPS whenever it is a little too busy.

SMART SCREEN COPIES
Xenia copies every picture the game draws back from the graphics card, because Sim portraits need it.
On many PCs that copying is what keeps the game far below 60 FPS. With Smart screen copies on, the game asks
for copies only while it draws portraits, thumbnails, save pictures and screenshots, and the launcher switches
them on just for that moment. On the test PC this took the game from 15 to 60 FPS (about 52 while spinning the
camera zoomed out), with every portrait correct.
OUTFITS: Smart screen copies also makes each of those copies twice. That works around a Xenia bug that left
patches of other textures in Sims' clothes, hair, hats and jewellery after Create a Sim. An outfit saved while
broken stays broken in that save: pick Edit in CAS on that Sim in the mod menu, choose Done, then save, and the
outfits are built again.
HOUSEHOLD PICTURES: it also stops the family picture on the save menu and in household creation coming out as
speckled outlines. The game makes that picture again every time you save, so one save replaces a broken one.
PETS: the same patch file also carries "Pets look right", a fix in the game's own code that keeps dogs and cats
in shape at full speed, even with the whole town gathered round. Without it, pets showed holes and spikes, and in
a crowd their meshes stretched across the map. If a pet ever still looks wrong on your PC, press 6 for Pet safe
mode: pets are always right, but the frame rate drops while they are on screen, most of all zoomed out
(36 to 40 on the test PC, against 52 without it).
New Sims coming into view (say, the first time you zoom out) cost a short hitch of about half a second each
while their portraits are made.
It only works when you start the game with "Play Sims 3 Pets (Mod Menu).bat". Started any other way, the game
runs exactly as before. If a portrait ever comes out wrong, press 4 again to turn it off.

FPS COUNTER
Press 5 in "Sims 3 Pets FPS Patch.bat" to turn the counter on or off. When it is on, starting the game with
"Play Sims 3 Pets (Mod Menu).bat" shows a small box in the top-left corner, for example "15 / 60 FPS":
15 frames in the last second, out of the 60 the patch allows (30 without it). It hides while another window
is in front and closes with the game. If the first number stays well below the second, your PC is the limit.

GOOD TO KNOW
Nothing here changes your game file or Xenia's own files. The menu only exists while this launcher has the game running.
Some options change your save for good once you save (Die By, Bulldoze, Move Household Out, Delete It,
the relationship options and the move-in options).
Developer Tools are the game's unfinished test options, so a few may do nothing or misbehave.

The full option list and the Xenia fixes are in the README on the project page.
